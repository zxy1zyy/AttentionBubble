# AttentionBubble

AttentionBubble is a minimalist iOS app designed to help users improve focus,
self-regulation, and awareness of energy levels. It combines simple task
management, focus/break scheduling, and lightweight running-based performance
formulas with a clean, animated interface.  
The open-source version includes UI, data models, CloudKit syncing, HealthKit
integration, and Apple Watch connectivity — while keeping AI reasoning and
reinforcement learning scheduling logic private.


---

## 🏗️ Tech Stack

- **SwiftUI**  
- **CloudKit**  
- **HealthKit**  
- **CoreMotion / CoreLocation**  
- **WatchConnectivity**  
- **MVVM Architecture**  
- **Xcode 16+ / iOS 17+ recommended**
